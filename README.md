# ContextMenuManager · Windows 右键菜单管理器

右键菜单太长、常用命令找不到，或者想一次复制多个文件的完整路径？用 ContextMenuManager 可以按场景管理 Windows 右键菜单：关闭不常用的项目、添加自己的命令，也可以调整 Windows 11 的右键菜单样式。

**[下载 Windows x64 便携版](https://github.com/NeoLi-Coder/ContextMenuManager/releases)** · [问题反馈](https://github.com/NeoLi-Coder/ContextMenuManager/issues)

## 功能清单

### 按右键位置管理

| 在哪里点右键 | 可管理的菜单 |
| --- | --- |
| 文件或文件夹 | 文件、文件夹、目录各自的菜单，以及文件和文件夹共用的「所有对象」菜单。 |
| 空白处 | 目录背景、桌面背景的菜单。 |
| 系统对象 | 磁盘分区、「此电脑」、回收站、库和库目录背景的菜单。 |
| 特定文件 | LNK 快捷方式、UWP 应用快捷方式、EXE，以及未关联打开方式的未知格式；也可以按扩展名或按感知类型（如图像、音频）查找。 |
| 特定目录 | 按文档、图像、视频、音频等目录类型查看相应规则。 |

### 整理系统菜单

- **新建**：管理桌面或目录空白处右键里的「新建」项目；对支持的项目可编辑文件初始数据、调整是否显示在分割线上方。
- **发送到**：整理「发送到」子菜单中的目标。
- **打开方式**：管理文件右键菜单中的打开方式项目。
- **Win+X**：整理右键点击「开始」按钮时出现的快捷菜单。
- **右键拖拽**：管理按住鼠标右键拖动文件后出现的菜单。
- **Windows 11 菜单样式**：为当前用户切换 Win11 默认右键菜单或 Win10 经典样式。

### 编辑菜单项

- **查找和停用**：搜索当前列表，使用开关启用或停用项目。
- **添加命令和子菜单**：填写菜单文本、程序或命令及参数；可创建一级或多级菜单，并编辑子菜单项目。
- **调整外观与位置**：对支持的项目更改名称、图标或盾牌标记，以及设置默认位置、置顶或置底。
- **调整显示和运行方式**：对支持的项目设置仅按住 Shift 时显示、仅在资源管理器中显示，或修改命令、设置提升权限。

### 增强功能与排查工具

- **复制路径**：支持文件、文件夹混选，输出完整路径，每行一条；提供反斜杠和正斜杠两种格式。
- **增强菜单和详细编辑**：从规则列表添加便捷菜单项，或调整系统和部分第三方程序已有的菜单设置。
- **菜单分析**：分析指定对象的菜单来源；可从项目详情查看对应文件或注册表位置，并导出注册表项。
- **进阶管理**：编辑公共引用的 Shell 子菜单、管理自选注册表路径；用「GUID 锁」隐藏部分依赖 GUID 的 ShellEx 项目。
- **备份恢复**：在批量调整前备份菜单，需要时恢复。

### 清理右键菜单

按文件、文件夹等场景查看菜单。用顶部搜索框找项目，关掉右侧开关即可停用，以后需要时再打开。在 Windows 11 上，也可以切换当前用户的默认右键菜单与经典菜单样式。

### 添加和整理常用命令

在对应场景选择“新建一个菜单项目”，把常用程序或命令放进右键菜单，也可以修改现有项目的名称和图标。除了文件和文件夹，还能管理“新建”“发送到”“打开方式”、指定文件类型及 Win+X 菜单。需要排查某个菜单项来自哪里时，可以定位对应的注册表项或文件。

程序支持菜单备份和恢复。批量调整前建议先备份；如果菜单是由其他管理工具停用的，请先用原工具恢复。

### 一次复制多个完整路径

打开 **其他规则 → 所有对象**，启用“复制路径”或“复制路径（正斜杠）”。回到资源管理器，选中文件、文件夹，或混选两者，再点对应的右键菜单项：

| 菜单项 | 剪贴板示例 |
| --- | --- |
| 复制路径 | `C:\项目\说明.txt` |
| 复制路径（正斜杠） | `C:/项目/说明.txt` |

多选时每行一条路径，单选时没有额外换行，结果不带引号。两种格式都支持中文、空格、特殊字符、盘符根目录和 UNC 网络路径。

## 下载与使用

1. 从[本仓库发布页](https://github.com/NeoLi-Coder/ContextMenuManager/releases)下载 `*-win-x64-portable.zip`。
2. 解压整个 ZIP，再运行 `ContextMenuManager.exe`。请保留同目录的辅助程序和其他文件，复制路径功能需要随包提供的辅助程序。
3. 首次使用时，可以先关闭一个不常用的菜单项，再回到资源管理器右键确认效果。

便携版面向 Windows x64，基于 .NET 10 / WPF，发布包已包含运行时，无需另装 .NET。配置、语言字典和备份默认保存在程序旁的 `Data` 目录；如果程序旁没有 `Data`、但已有 AppData 数据，则继续使用原数据。

## 本分支的变化

- **复制路径**：改由独立辅助程序写入剪贴板，支持多选和两种斜杠格式。程序会识别并迁移本程序旧版的复制路径菜单，修改注册表前备份到 `Data/RegBackup/<计算机名>/CopyPathUpgrade`；用户字典中同名的菜单不自动迁移。
- **窗口位置**：关闭普通状态的窗口时记住位置；首次启动在鼠标所在显示器居中。显示器或工作区变化时，会按目标显示器 DPI 恢复并调整越界的窗口。
- **中文与便携**：保留简体中文和繁体中文，移除程序内捐赠入口。发布包包含语言、菜单字典和复制路径辅助程序。
- **更新来源**：本分支版本请以[本仓库发布页](https://github.com/NeoLi-Coder/ContextMenuManager/releases)为准。程序内更新检查、在线字典和语言下载仍使用上游配置，更新检查可能打开上游发布页。

## 本地打包

在仓库根目录使用 PowerShell 7 执行：

```powershell
./scripts/Publish-Portable.ps1
```

本地和 GitHub 发版使用同一打包入口，输出为 `ContextMenuManager/bin/<版本号>/*-portable.zip`。分发时使用完整 ZIP；普通构建目录 `bin/Release` 不是便携发布包。

验证复制路径的两种格式：

```powershell
pwsh -NoProfile -STA -File ./scripts/Verify-CopyPath.ps1
```

脚本默认使用本地发布目录，也可通过 `-HelperPath` 指定辅助程序；验证结束后会恢复原剪贴板内容。
